# Victor M. Preciado

I work on dynamical systems, control, and network science. Here you’ll find selected research papers and the code that accompanies them, followed by my course and book materials.

## Research papers and companion code

### Neurosymbolic Synthesis of Contraction Metrics with Certified Verification

Counterexample-guided synthesis of contraction metrics for continuous-time systems, with numerical certification. Release **v1.2.2** contains the paper and the versioned reproduction package.

[Paper (PDF)](https://github.com/vmpreciado/NeuroSymbolic/releases/download/v1.2.2/neurosymbolic-paper-v1.2.2.pdf) · [Companion code](https://github.com/vmpreciado/NeuroSymbolic) · [Reproduction release v1.2.2](https://github.com/vmpreciado/NeuroSymbolic/releases/tag/v1.2.2)

### A Measure-Theoretic Formulation of Behavioral Systems

A formulation of behavioral systems in terms of probability measures on admissible trajectories, with numerical studies on control and data-driven trajectory representations.

[Preprint](https://arxiv.org/abs/2605.01558) · [Companion code](https://github.com/vmpreciado/behavioral-systems-measures)

### Optimal Multiharmonic Forcing Design for Homoclinic Chaos Control via Convex Optimization

Optimization and simulation code for designing multiharmonic forcing to control chaos in nonlinear oscillators. Joint work with Ricardo Chacón.

[Companion code and citation](https://github.com/vmpreciado/Melnikov_Chaos_Control)

### A Koopman-Port-Hamiltonian Framework for Data-Driven Modeling and Control

Structure-preserving system identification and control, illustrated with a two-link robot model.

[Companion code and citation](https://github.com/vmpreciado/CDC2026_KpH)

### Disentangling Epidemic Rates and Network Structure from Multi-Stream Surveillance Data

Code and synthetic data for estimating epidemic rates and network structure from multiple surveillance streams.

[Companion code and data](https://github.com/vmpreciado/2026_CDC_Epidemics)
